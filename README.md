A full-stack Student Management System built using Java, Spring Boot, Spring Data JPA, Hibernate, Thymeleaf, MySQL, and Spring Security.

## 🚀 Live Demo

https://student-management-euzx.onrender.com

## ✨ Features

- Student Registration
- Update Student Details
- Delete Student
- View Student Information
- Search Students
- Pagination
- Dashboard Statistics
- Spring Security Login
- Form Validation
- Responsive UI

## 🛠️ Tech Stack

### Backend
- Java 
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security

### Frontend
- Thymeleaf
- HTML
- CSS
- Bootstrap

### Database
- MySQL

### Deployment
- Docker
- Render



## ⚙️ Installation

```bash
git clone https://github.com/faisalpathan1210/Student_Management.git
```

Configure your database in:

```
src/main/resources/application.properties
```

Run:

```bash
mvn spring-boot:run
```
